# Безопасность

## Как сообщить об уязвимости

Не открывайте публичный issue. Нажмите «Report a vulnerability» на вкладке **Security** или напишите мне в Telegram: [@BehruzAvezmatov](https://t.me/BehruzAvezmatov).

## Что сделано

- API слушает только `127.0.0.1`. Открыть его в сеть можно явно, переменной `BUBBLE_API_HOST`.
- CORS разрешён только адресам дашборда (`BUBBLE_CORS_ORIGINS`), команды `stop` и `reset` требуют заголовок `X-Bubble-Client: dashboard`, WebSocket проверяет `Origin`. Посторонний сайт в браузере оператора не может управлять трекером или читать статистику.
- `session_id` проверяется шаблоном до того, как попадёт в путь к файлу и в `glob`, поэтому `..\` и `*` не выведут за пределы папки результатов. Это покрыто тестом.
- Ответы с ошибками не содержат текст исключений.
- В Docker порты опубликованы только на `127.0.0.1`, образ API работает не от root, папка результатов смонтирована только на чтение.

GitHub Actions на каждый push запускает тесты API, `pip-audit`, `npm audit`, lint и сборку дашборда, а также `gitleaks` по всей истории.
